**Author**: menkos
**Version**: 1.2.0 (Godot 4.0)
**License**: MIT
**Last Updated**: 2026-01-06

## Installation

1. Open project in Godot Engine
2. Click **AssetLib** tab
3. Search for "Inventory Forge"
4. Click Download → Install
5. Enable in **Project → Project Settings → Plugins**

## Features

- Drag-and-drop inventory UI
- Item stacking
- Equipment slots
- Custom item properties
- Save/load support

## Integration with LICHCRAFT

Perfect for tracking:
- Possessions (physical items)
- Relationships (NPC connections as items)
- Beliefs (ideology items)
- Humanity (transformation progress items)

### Sacrifice Mechanic
- Customize item types for sacrifice system
- Track what player gives up for survival
- Integrate with GameState.inventory
