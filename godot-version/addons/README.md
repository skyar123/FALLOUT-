# Addons Directory

This directory contains Godot Asset Library plugins for LICHCRAFT.

## 📥 Installation Instructions

Plugins must be installed via Godot Engine's AssetLib tab or manually downloaded.

See [../ASSET_LIBRARY_GUIDE.md](../ASSET_LIBRARY_GUIDE.md) for detailed installation instructions.

## 📂 Directory Structure

- `dialogue_manager/` - Dialogue Manager 3 (nathanhoad)
- `inventory_forge/` - Inventory Forge (menkos)
- `nexus_quest_weaver/` - Nexus Quest Weaver (movec)
- `skelerealms/` - Skelerealms Open World RPG Framework (Slashscreen)
- `turn_based_combat/` - Turn Based Combat system (TheRealFame)

## ⚠️ Important

These directories are currently empty placeholders. You must:

1. Open the project in Godot Engine
2. Go to **AssetLib** tab
3. Search for and install each plugin
4. Enable plugins in **Project → Project Settings → Plugins**

Alternatively, download assets manually and extract to the appropriate subdirectory.
