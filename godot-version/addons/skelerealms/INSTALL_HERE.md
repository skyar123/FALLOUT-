# Skelerealms - Open World RPG Framework

**Author**: Slashscreen
**Version**: 0.6 (Godot 4.3)
**License**: MIT

**HIGHLY RECOMMENDED** for LICHCRAFT

## Installation

1. Open project in Godot Engine
2. Click **AssetLib** tab
3. Search for "Skelerealms"
4. Click Download → Install
5. Enable in **Project → Project Settings → Plugins**

## Features

- World exploration system
- NPC interaction framework
- Location management
- Event system
- Save/load game state

## Why Perfect for LICHCRAFT

- Built for exploration-heavy RPGs
- Prime City Streets exploration
- Multiple interconnected locations
- NPC-rich world
- Story-driven exploration

## Integration
