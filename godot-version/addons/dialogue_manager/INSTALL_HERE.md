**Author**: nathanhoad
**Version**: 3.9.1 (Godot 4.4)
**License**: MIT

## Installation

1. Open project in Godot Engine
2. Click **AssetLib** tab
3. Search for "Dialogue Manager"
4. Click Download → Install
5. Enable in **Project → Project Settings → Plugins**

## Alternative: Manual Installation

1. Download from [Godot Asset Library](https://godotengine.org/asset-library/asset)
2. Extract contents to this directory
3. Restart Godot
4. Enable in Project Settings → Plugins

## Features

- Branching conversation trees
- Variable and condition system
- Character portraits and emotion support
- Save/load dialogue state
- Custom `.dialogue` file format

## Integration with LICHCRAFT

- Replace or extend current `DialogueSystem.gd`
- Convert dialogue trees to `.dialogue` files
- Connect to GameState flags and variables
- Integrate with NPC interaction system
